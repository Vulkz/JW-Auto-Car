# JW Auto Car — Landing Page

Descrição
-----
Pequena landing page para o projeto "JW Auto Car". Conteúdo estático em HTML, CSS e JavaScript para apresentação de serviços/veículos.

Estrutura do diretório
-----
- `index.html` — página principal da landing.
- `Css/styles.css` — estilos principais (atenção ao nome da pasta com C maiúsculo).
- `Js/main.js` — scripts da página.
- `img/` — imagens e assets usados pela landing.

Como visualizar localmente
-----
Opções rápidas:

- Abrir `index.html` diretamente no navegador.
- Ou servir via servidor simples (recomendado para testes com fetch/imports):

  - Python 3:

    ```bash
    python -m http.server 8000
    ```

    Acesse http://localhost:8000/landing-jw-auto-car/

Como editar
-----
- HTML: editar `index.html` para alterar conteúdo e marca.
- CSS: ajustar `Css/styles.css` para personalizar estilos.
- JS: atualizar `Js/main.js` para comportamento/interações.
- Imagens: substituir arquivos em `img/` mantendo os nomes ou atualizando referências no HTML/CSS.

Boas práticas
-----
- Mantenha backup antes de alterações significativas.
- Teste em mobile/responsivo ao editar estilos.
- Verifique caminhos (case-sensitive) se utilizar servidores linux/production.

Deploy
-----
Esta é uma página estática; pode ser hospedada em serviços como GitHub Pages, Netlify ou Vercel.
